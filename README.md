## ✦ 自己紹介

> *「面白い人間でありたい。そして、誰かの記憶に残るものを生み出したい。」*

&nbsp;

**Agent エンジニア** 🤖 として、LLM を使った自律エージェントの設計・開発に取り組んでいます。\
オープンソースと面白いものすべてが大好き。\
右側にいるのは **[SageWizWang](https://github.com/rwerplus/rwerplus)**、バーチャル世界での僕の分身です。
